* Backup nvim files:
	$ rm -rf ~/.config/nvim
	$ rm -rf ~/.local/share/nvim
	$ rm -rf ~/.local/state/nvim
	$ rm -rf ~/.cache/nvim
* Install useful binaries that neovim likes to use:
	brew install fzf lazygit fd ripgrep
* Clone the lazyvim starter repo, and remove the '.git/' dir
	$ git clone https://github.com/LazyVim/starter ~/.config/nvim
	$ rm -rf ~/.config/nvim/.git
